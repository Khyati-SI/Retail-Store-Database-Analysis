
#  Retail Store SQL Analysis

A SQL-based retail store analysis project designed to explore customer activity, products, orders, payments, and product reviews using relational database concepts and business-oriented SQL queries.

##  Project Overview

This project simulates a retail store database and demonstrates how SQL can be used to answer common business questions related to customers, products, sales, payments, inventory, and customer engagement.

The database contains multiple related tables connected through primary and foreign keys.

The project was completed as part of a **SQL Mini Project** under Data Analytics with GenAI.

##  Database Schema

The database contains the following tables:

* **Customers** – Customer information such as name, email, phone number, and account creation date.
* **Products** – Product information including category, price, and stock quantity.
* **Orders** – Customer orders, order dates, order status, and total amounts.
* **Order Items** – Individual products included in each order, along with quantity and item price.
* **Payments** – Payment information including payment method, amount paid, and payment date.
* **Product Reviews** – Customer ratings and reviews for products.

The relationships between these tables are primarily implemented using foreign keys. For example, a customer can place multiple orders, while an order can contain multiple order items.

##  Database Relationships

```text
Customers
    │
    └──< Orders
             │
             ├──< Order Items >── Products
             │
             └──< Payments

Customers
    │
    └──< Product Reviews >── Products
```

Key relationships include:

* Customers → Orders: **One-to-Many**
* Orders → Order Items: **One-to-Many**
* Products → Order Items: **One-to-Many**
* Orders → Payments: **One-to-Many**
* Products → Product Reviews: **One-to-Many**
* Customers → Product Reviews: **One-to-Many**
